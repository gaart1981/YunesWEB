# Salimi Engineering website

Multilingual corporate website for a Morocco-based, founder-led engineering and project advisory business.

## Current implementation state

The first reviewable foundation includes:

- Next.js App Router;
- English, French and Arabic home pages;
- complete Arabic RTL direction;
- JSON-driven visible business content;
- responsive smartphone, tablet and desktop layouts;
- approved Quiet Engineering Confidence visual direction;
- branded placeholders for future authorised photography;
- explicit noindex state until factual, legal and contact information is approved.

This is a foundation preview. It is not yet approved for advertising or search indexing.

## Local commands

```bash
npm install
npm run typecheck
npm run build
```

The binding requirements remain in `/source_docs`.
